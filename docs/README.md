# Guia do projeto

O manual em português está em `CyberShield-Guia-Completo.pdf`, acompanhado de `Guia-CyberShield.md` e `build_guide.py`. O PDF inclui exemplos extraídos dos arquivos reais, diagramas, capturas da interface e exercícios.

O objetivo é explicar o caminho completo do HTML ao banco: DOM e eventos, módulos JavaScript, Fetch/HTTP, rotas Express, validação, SQLite, hashing de senhas, cookies de sessão, CSRF, testes e limites de implantação.

Os arquivos antigos estão preservados em `docs/original/` para comparação com a versão final. O conteúdo desta pasta não é servido pelo Express. Os resultados dos testes de navegador estão em `e2e-results.json`; a validação do documento está em `pdf-validation.json`.
